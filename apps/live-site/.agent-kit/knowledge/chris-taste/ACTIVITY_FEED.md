# Activity feed

**Source:** Chris, Oct–Nov 2026.

## Rule

Lobby / homepage **Activity** is the live bet **table only** — heading + feed. No pill sub-nav.

## Do not

- Do not add **Jackpot Winners** or **25k Daily Races** (or All Bets) filters above the table.
- Race / jackpot surfaces live elsewhere (VIP Hub, promotions) — not as Activity tabs.
- Do **not** put a HoverCard / preview popover on Activity rows (Bet / Payout / Play {game}). Tap/click the game name launches only — no sticky card.
